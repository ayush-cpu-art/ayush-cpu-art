## AI Resume Analyzer

**AI-powered resume-to-job matching and analysis system**

Built an end-to-end application that analyzes a resume against a target job description using ATS-style skill matching and semantic similarity.

- Built a **FastAPI backend** for resume processing and analysis
- Extracted resume text from PDF files using **PyMuPDF**
- Implemented skill extraction with **skill aliases and normalization**
- Developed ATS-style matching to identify **matched and missing skills**
- Used **Sentence Transformers (`all-MiniLM-L6-v2`)** for semantic similarity
- Combined ATS and semantic scores into an overall compatibility score
- Generated recommendations based on missing skills
- Generated downloadable **PDF analysis reports** using ReportLab
- Implemented upload validation, file-size limits, filename sanitization, and secure report downloads
- Added **15 automated tests** covering analyzer logic and API behavior

**Repository:**  
https://github.com/ayush-cpu-art/AI-RESUME-ANALYZER
